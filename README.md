# DISCIPLINA TOTAL
Tracker personal en español para hábitos, alimentación, hidratación, entrenamiento, estudio, finanzas, ahorro, inversión, sueño y productividad.

## Uso
Abre `index.html` en Chrome o Edge. Los datos se guardan localmente en el navegador.
Usa "Copia de seguridad" para exportar un JSON.

Incluye una interfaz oscura estilo militar, frases de disciplina y versículos bíblicos.

## Próxima versión
Se puede convertir en una app instalable para Android/iPhone, con cuenta, sincronización, notificaciones, gráficos, calendario, presupuestos y seguimiento avanzado de inversiones.
